SHELL SCRIPT TOP FUNCTION NAMES
====================================
These are the names that show up most often in Bash and POSIX sh scripts:
installers, CI scripts, dotfiles, ops tooling, and style guides such as
Google's Shell Style Guide. The list is curated from common practice; it is
not a statistically measured ranking.

Conventions
-----------
- Use lower_snake_case for function names. Reserve UPPERCASE for variables.
- Never name a function after a shell builtin, such as test, help, echo,
  read, wait, cd, or type. That is why this list uses "show_help", not "help".
- Some common names shadow external commands inside the script. For example,
  "info" shadows GNU info and "log" shadows the macOS log command. That is
  fine as long as the script never needs the real command.
- Prefix subcommand handlers, for example cmd_start and cmd_install, so they
  don't collide with real commands like /usr/bin/install.
- Call main last: main "$@"

 #   NAME                  PURPOSE
---  --------------------  ---------------------------------------------------

[ Entry point & lifecycle ]
  1. main                  Entry point; invoked at the bottom as main "$@"
  2. usage                 Print usage/synopsis (often then exit 1)
  3. show_help             Print full help text (avoids the 'help' builtin)
  4. version               Print script version
  5. parse_args            Parse CLI flags with getopts / while-case loop
  6. init                  Initialize state, defaults, directories
  7. setup                 One-time environment preparation
  8. cleanup               Remove temp files/locks; usually bound to trap EXIT
  9. run                   Execute a command (often with logging / dry-run)
 10. finish                Final summary / teardown at normal exit

[ Logging & output ]
 11. log                   Generic timestamped log line
 12. info                  Informational message
 13. warn                  Warning message (to stderr)
 14. error                 Error message (to stderr)
 15. debug                 Message shown only when DEBUG/VERBOSE is set
 16. die                   Print error and exit non-zero
 17. fatal                 Alias-style variant of die
 18. msg                   Plain message helper (printf wrapper)
 19. success               Green "OK"/checkmark message
 20. log_info              Level-prefixed logger: INFO
 21. log_warn              Level-prefixed logger: WARN
 22. log_error             Level-prefixed logger: ERROR
 23. log_debug             Level-prefixed logger: DEBUG
 24. timestamp             Emit current date/time string
 25. print_header          Section header for output
 26. print_banner          Larger banner / title block
 27. separator             Horizontal rule line
 28. colorize              Wrap text in ANSI color codes (respect NO_COLOR)

[ Error handling & signals ]
 29. on_error              Handler for trap ERR (report line/command)
 30. on_exit               Handler for trap EXIT
 31. handle_signal         Handler for INT/TERM/HUP
 32. abort                 Stop execution with a reason
 33. assert                Fail if a condition is false
 34. retry                 Re-run a command N times with backoff
 35. try                   Run a command, capture failure without exiting

[ Validation & checks ]
 36. require               Generic precondition check
 37. require_root          Exit unless running as root (EUID 0)
 38. require_cmd           Exit unless a command is on PATH
 39. check_deps            Verify all required tools are installed
 40. command_exists        Return 0 if command -v finds it
 41. is_root               Boolean: running as root?
 42. is_installed          Boolean: package/binary installed?
 43. is_number             Boolean: argument is an integer?
 44. is_empty              Boolean: string/dir empty?
 45. validate_input        Sanitize/validate user-supplied values
 46. check_os              Ensure supported OS/distro
 47. check_network         Verify connectivity / DNS

[ Interactive prompts ]
 48. confirm               Yes/no confirmation (honor --yes)
 49. prompt                Ask for a value with optional default
 50. ask_yes_no            Explicit y/n loop
 51. read_password         Read secret input with read -rs
 52. select_option         Menu selection (select / case)
 53. pause                 "Press any key to continue"

[ Files & directories ]
 54. backup_file           Copy file to *.bak / timestamped backup
 55. ensure_dir            mkdir -p with permission handling
 56. file_exists           Boolean: [ -f "$1" ]
 57. dir_exists            Boolean: [ -d "$1" ]
 58. make_temp             mktemp wrapper registered for cleanup
 59. safe_rm               rm with guard rails (no empty/"/" paths)
 60. copy_files            cp/rsync wrapper
 61. download              curl/wget wrapper with retries
 62. extract               Unpack tar/zip/gz by extension
 63. checksum              Compute/verify sha256

[ Strings & arrays ]
 64. trim                  Strip leading/trailing whitespace
 65. to_lower              Lowercase a string
 66. to_upper              Uppercase a string
 67. join_by               Join array elements with a delimiter
 68. split_string          Split a string into an array (avoids /usr/bin/split)
 69. contains              Boolean: substring present?
 70. starts_with           Boolean: prefix match
 71. ends_with             Boolean: suffix match
 72. urlencode             Percent-encode a string
 73. in_array              Boolean: value present in array?

[ System & processes ]
 74. detect_os             Identify OS/distro (via /etc/os-release, uname)
 75. get_arch              Normalize uname -m (x86_64/amd64, arm64/aarch64)
 76. install_package       Distro-agnostic dnf/apt/brew wrapper
 77. update_system         Refresh/upgrade packages
 78. restart_service       systemctl/launchctl restart wrapper
 79. is_service_running    Boolean: service active?
 80. get_ip                Primary IP address
 81. kill_process          Terminate by name/PID gracefully, then force
 82. wait_for              Poll until a condition is true or timeout
 83. wait_for_port         Poll until a TCP port accepts connections
 84. spinner               Animated spinner for long tasks
 85. progress_bar          Textual progress indicator
 86. elapsed_time          Human-readable duration since START_TIME

[ Configuration & environment ]
 87. load_config           Source/parse a config file
 88. load_env              Load KEY=VALUE pairs from a .env file
 89. get_config            Read a config value with default
 90. set_config            Write/update a config value
 91. source_if_exists      Source a file only if it is present

[ Locking & concurrency ]
 92. acquire_lock          flock / mkdir-based lock
 93. release_lock          Release the lock (also in cleanup)
 94. is_running            Boolean: another instance active? (PID file)

[ Subcommand handlers ]
 95. cmd_start             "script start" handler
 96. cmd_stop              "script stop" handler
 97. cmd_restart           "script restart" handler
 98. cmd_status            "script status" handler
 99. cmd_install           "script install" handler
100. cmd_deploy            "script deploy" handler
